### 4. Prerequisites & Local Development

#### Prerequisites
- .NET 8.0 SDK

#### Installation
```bash
git clone https://github.com/reginaldalfret/portfolio-blazor.git
cd Portfolio-Blazor
dotnet restore
```

#### Running Development Server
```bash
dotnet run
```

#### Production Build
```bash
dotnet publish -c Release -o dist
```

#### Running Test Suite
```bash
dotnet test
```
